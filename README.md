# 🛒 Quicklist — Lista de Compras

Aplicação web para criar e gerenciar listas de compras de forma simples e rápida. Permite adicionar itens, marcar como comprados e removê-los da lista, com feedback visual ao usuário.

Este projeto foi desenvolvido como **atividade complementar de um curso da [Rocketseat](https://www.rocketseat.com.br/)**, com **HTML5**, **CSS3** e **JavaScript puro (Vanilla JS)**, sem frameworks ou bibliotecas externas de UI.

## 🔗 Demo

🔗 [site-lista-de-compras.vercel.app](https://site-lista-de-compras.vercel.app/)

## 🖼️ Preview

![Preview do site](../assets/preview.png)

## 🚀 Funcionalidades

- ➕ Adicionar novos itens à lista de compras
- ✅ Marcar itens como comprados através de checkbox
- 🗑️ Remover itens da lista
- 🔔 Alerta visual informando quando um item é removido
- 🎨 Interface limpa, com ícones e tipografia customizada (Google Fonts: Inter e Sora)

## 🛠️ Tecnologias utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**
- [Google Fonts](https://fonts.google.com/)

## 📁 Estrutura do projeto

```
Site-Lista-de-Compras/
├── assets/          # Ícones e imagens (logo, lixeira, alerta, etc.)
├── css/
│   └── style.css    # Estilização da aplicação
├── js/
```

## ▶️ Como executar

Não é necessário nenhuma instalação ou dependência. Basta clonar o repositório e abrir o arquivo `index.html` no navegador:

```bash
git clone https://github.com/vinicius-lds04/Site-Lista-de-Compras.git
cd Site-Lista-de-Compras
```

Depois, abra o arquivo `index.html` diretamente no navegador (duplo clique) ou utilize uma extensão como o **Live Server** no VS Code para visualizar com recarregamento automático.
